# 地理编码服务代码地图

## 模块职责

地理编码服务负责：
- 地址转坐标（正向地理编码）
- 坐标转地址（反向地理编码）
- 离线地理编码支持

## 关键文件

| 文件 | 职责 |
|------|------|
| `services/location_geocode/` | 地理编码SA目录 |

## 高风险入口

| 入口函数 | 说明 |
|----------|------|
| `Geocode()` | 正向地理编码 |
| `ReverseGeocode()` | 反向地理编码 |

## 编译单元

```gn

```
